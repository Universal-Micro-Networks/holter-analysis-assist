- [x] 1. Foundation: 埋め込み依存とアセット骨格を用意する
- [x] 1.1 静的コンソール用の埋め込み依存とアセットディレクトリ骨格を追加する

  - コンソール用アセット置き場の骨格を用意し、ビルドから参照できる状態にする
  - 解析・ライセンス・ヘルスの契約変更や SPA／Node ビルドは追加しない
  - 完了条件: 埋め込み依存込みでビルド解決でき、空またはプレースホルダのコンソールアセットを埋め込み型から参照できる

- [ ] 2. Core: コンソール画面と静的配信
- [ ] 2.1 (P) 日本語の簡易コンソール画面（アップロード／ヘルス／結果）を実装する
  - ECL 選択、解析実行、ヘルス確認、処理中表示、結果表示、ダウンロード、エラー表示を日本語文言で提供する
  - ブラウザから既存のヘルス経路と解析経路のみを同一オリジンで呼び出す（契約の再定義なし）
  - ファイル未選択時は解析を送らず日本語で不足を示す
  - 解析・ヘルスのために UI 側で利用計上を行わない
  - 臨床判定・波形・帳票・認証・課金画面は含めない
  - 完了条件: 静的ファイルとしてコンソールが揃い、主要な操作ラベル／案内／エラーが日本語で読める
  - _Boundary: ConsoleClient_
  - _Depends: 1.1_
  - _Requirements: 2.1, 2.2, 2.3, 3.1, 3.2, 3.3, 3.4, 4.1, 4.2, 4.3, 4.4, 5.1, 5.2, 5.3, 6.1, 6.3, 7.1, 7.2, 8.1, 8.2, 10.1, 10.2, 10.3_

- [ ] 2.2 (P) 埋め込みアセットをコンソール配信経路で返す

  - 任意でルート `/` から `/ui/` への誘導を行ってよい
  - ヘルス／解析経路と区別し、静的配信では利用計上を行わない
  - 欠落アセットは 404 とし、Content-Type を適切に付与する
  - 完了条件: ブラウザまたはテストクライアントで `/ui/` が HTML を返し、既知アセットが取得できる

  - _Depends: 1.1_
